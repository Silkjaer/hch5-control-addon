# HCH5 Control for Home Assistant

Home Assistant app (add-on) repository for HCH5 Control: local control of a
Dantherm HCH5 MK1 (RS485 TCP or USB adapter) or HCH5 MKII (Modbus).

Add this repository under **Settings → Apps → App store → ⋮ → Repositories**,
then install **HCH5 Control**. See [the app documentation](hch5_control/DOCS.md).

Unofficial community project, not affiliated with Dantherm.
